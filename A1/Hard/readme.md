# Assignment 1: CSS Positioning - Hard Challenge

## 📋 Overview

This assignment challenges you to recreate a complex UI design using CSS positioning properties. The goal is to build a pixel-perfect replica of a provided reference design, understanding how professional layouts leverage CSS positioning for complex arrangements.

**Reference Design:** See `task.png` in this directory for the design you need to replicate.

## 🎯 Objectives

- Master CSS positioning techniques: `position: relative` and `position: absolute`
- Understand how real-world UI layouts are constructed
- Build a close replica of the reference design with proper spacing and alignment
- Develop attention to detail in UI recreation
